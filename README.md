# PSE em Ação

### Sistema de Planejamento e Acompanhamento de Ações de Saúde na Escola

Projeto desenvolvido para a AEP 2026.2 — Unicesumar  
Engenharia de Software

---

## O Projeto

O **PSE em Ação** é uma aplicação desenvolvida em linguagem C com o
objetivo de auxiliar no planejamento, registro e acompanhamento de
ações coletivas do Programa Saúde na Escola.

O sistema permite organizar as informações das ações e acompanhar
seu desenvolvimento de forma simples e estruturada.

## Funcionalidades

**Cadastro**  
Registro das ações do PSE.

**Listagem**  
Visualização das ações cadastradas.

**Pesquisa**  
Pesquisa por código, escola ou tema.

**Atualização**  
Alteração da situação das ações.

**Participantes**  
Registro da quantidade de participantes.

**Validação**  
Verificação dos dados informados pelo usuário.

**Resumo geral**  
Apresentação dos principais dados das ações.
